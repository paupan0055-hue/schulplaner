Kostenloses Backend & Geräte-Synchronisation

Da GitHub Pages statisch ist, verbindet ein kostenloser Firebase Realtime Database URL-Endpunkt alle Geräte dauerhaft.

Cloud-Sync aktiv (Firebase)

So funktioniert das kostenlose Backend auf GitHub Pages:

1. Projekt im Spark-Plan auf console.firebase.google.com anlegen (dauerhaft kostenlos).

2. Realtime Database erstellen und die Regeln auf Lese-/Schreibzugriff setzen (siehe JSON unten).

3. Database-URL prüfen oder anpassen und auf Cloud-Sync speichern klicken.

Empfohlene Firebase Realtime Database Regeln (JSON):
{
  "rules": {
    "schulplaner_v1": {
      ".read": true,
      ".write": true
    }
  }
}
